1. 이 도구가 하는 일

AI 원픽 업로더는 채널 운영자 한 명이 자신의 컴퓨터에서만 사용하는 비공개 도구로, 운영자 본인의 YouTube 채널에 영상을 업로드하고 채널을 관리하는 데만 사용됩니다. 다른 사용자에게 제공되지 않습니다.

2. 이용하는 정보 (YouTube API 서비스)

운영자가 Google OAuth로 허용한 범위 안에서 운영자 본인 채널의 정보만 이용합니다.

  • 영상 업로드·예약 공개·AI 생성 콘텐츠 표시 (videos.insert)
  • 썸네일 설정 (thumbnails.set), 본인 영상에 댓글 작성 (commentThreads.insert)
  • 본인 채널 배너·브랜딩 설정 (channelBanners.insert, channels.update)

다른 YouTube 사용자의 개인정보는 수집·저장·이용·공유하지 않습니다.

3. 저장과 보관

OAuth 인증 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 전송하지 않습니다. 업로드용 영상·메타데이터 파일도 운영자의 컴퓨터에만 보관합니다. 토큰은 운영자가 접근 권한을 해제하거나 도구 사용을 중단하면 삭제합니다.

4. 제3자 제공

이용한 정보를 제3자에게 판매·제공하지 않습니다. 영상 제작에 Google Gemini API(대본·음성 생성)를 사용하며, 여기에는 공개된 뉴스 기사와 대본 텍스트만 전송됩니다.

5. 권한 해제

이 도구는 YouTube API 서비스를 사용합니다. 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. 접근 권한은 Google 보안 설정 - 서드 파티 앱 권한에서 언제든 해제할 수 있습니다.

Privacy Policy (English)

1. What this tool does

AI Wonpick Uploader is a private, single-user tool run by the channel owner on their own computer. It is used solely to upload videos to and manage the owner's own YouTube channel (@aiwonpick). It is not offered to any other user.

2. Information accessed (YouTube API Services)

Within the OAuth scopes granted by the owner, the tool accesses only the owner's own channel to: upload videos with scheduled publishing and synthetic-media disclosure (videos.insert); set thumbnails (thumbnails.set); post a comment on the owner's own videos (commentThreads.insert); and update the owner's channel banner/branding (channelBanners.insert, channels.update). It does not collect, store, use, or share any other YouTube user's personal data.

3. Storage and retention

OAuth tokens are stored only on the owner's computer and are never sent to any other server. Video files and metadata are kept locally. Tokens are deleted when access is revoked or the tool is no longer used.

4. Sharing

No data is sold or shared with third parties. The Google Gemini API is used to draft scripts and synthesize narration; only public news article text and script text are sent to it.

5. Revoking access

This tool uses YouTube API Services. By using it, the YouTube Terms of Service and the Google Privacy Policy apply. Access can be revoked at any time via Google security settings.
