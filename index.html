About the AI Wonpick Uploader (YouTube API client)

AI Wonpick Uploader is a private, single-user desktop tool run by the channel owner on their own computer. It is used only to manage the owner's own YouTube channel (@aiwonpick).

Workflow: the tool drafts a short video from public AI news articles → the channel owner reviews and approves the script → the tool renders the video and uploads it to the owner's channel with the YouTube Data API.

YouTube API features used: videos.insert (upload, scheduled publishing, AI/synthetic-content disclosure), thumbnails.set, commentThreads.insert (one pinned-comment draft on the owner's own video), channelBanners.insert / channels.update (the owner's own channel branding).

It does not access, collect, or display any other user's data, and it is not offered to other users.
